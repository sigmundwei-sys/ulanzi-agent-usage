Ulanzi Agent Usage

這個 action 會直接使用對應 provider 的 adapter，每 5 分鐘更新一次。設定檔放在本機，不會同步到 repository。

Codex

npm install --global @openai/codex 後執行 codex login。Plugin 透過官方 app-server 讀取 rate limits。

Grok

先執行 grok login。Grok Weekly Usage 顯示共用每週池，GrokBuild Usage 顯示其中的 GrokBuild 用量。

Cursor

Experimental：設定 CURSOR_SESSION_TOKEN，或依 README 設定本機 config。

Antigravity

Experimental：安裝 antigravity-usage，並確認 antigravity-usage --json 可正常回傳資料。

OpenCode Go

安裝並設定 @slkiser/opencode-quota，再依 README 設定 workspace 與 cookie。

完整設定、隱私界線與故障排查：GitHub repository 的 README。
