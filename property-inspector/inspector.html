Setup required

This plugin reads your Claude Code OAuth token to show API usage.

Windows

  1. Install: npm install -g @anthropic-ai/claude-code
  2. Sign in: claude auth login
  3. Credentials saved to %USERPROFILE%\.claude\.credentials.json

macOS

  1. Install: brew install claude-code
  2. Sign in: claude auth login

Usage data cached 3 min. Click button to force refresh.

Token refreshes automatically when expired.
